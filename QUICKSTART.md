# Швидкий старт - Modern ToolBar для Delphi

## 🚀 Швидке встановлення та запуск

### Крок 1: Відкриття проекту
1. Відкрийте Delphi IDE (версія 10.3 Rio або новіша)
2. Відкрийте файл `ModernToolBarProject.groupproj` або `DemoApp.dpr`

### Крок 2: Компіляція та запуск
1. Натисніть `F9` або `Run > Run` для компіляції та запуску
2. Демонстраційна програма відкриється в повноекранному режимі

## 📁 Структура файлів

### Основні компоненти:
- `ModernToolBar.pas` - Головний компонент сучасної панелі інструментів
- `SVGRenderer.pas` - Рендерер для SVG іконок  
- `HighDPISupport.pas` - Підтримка високої роздільності
- `IconSets.pas` - Менеджер наборів іконок

### Демонстраційна програма:
- `DemoApp.dpr` - Головний файл проекту
- `MainForm.pas` / `MainForm.dfm` - Головна форма демо
- `DemoApp.dproj` - Файл конфігурації проекту

## 🎮 Як користуватися демо

### Панель налаштувань (праворуч):
1. **Набір іконок** - Вибирайте серед Material Design, Feather, Font Awesome тощо
2. **Тема** - Переключайтеся між світлою, темною та автоматичною темою
3. **Розмір іконок** - Змінюйте від 16px до 64px
4. **Особливості** - Увімкніть/вимкніть High DPI, згладжування, анімації
5. **Браузер іконок** - Переглядайте та шукайте серед доступних іконок

### Головна панель інструментів:
- Всі кнопки функціональні та показують дії в лог-області
- Спробуйте різні налаштування та побачите зміни в реальному часі

## 💡 Швидке використання в своєму проекті

```pascal
uses
  ModernToolBar, IconSets;

// Створюємо панель інструментів
var ToolBar := TModernToolBar.Create(Self);
ToolBar.Parent := Panel1;
ToolBar.Align := alTop;

// Додаємо кнопки з сучасними іконками
ToolBar.AddButton('Новий', 'document-plus', @OnNewClick);
ToolBar.AddButton('Відкрити', 'folder-open', @OnOpenClick);
ToolBar.AddButton('Зберегти', 'save', @OnSaveClick);
```
